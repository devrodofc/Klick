# Klick — Banco de ideias

> Ideias para explorar, **não requisitos confirmados**. Mover para o [GDD](GDD.md) quando forem testadas e aprovadas.

## Possíveis puzzles

- **Balança:** mudar o peso para ativar ou desativar uma plataforma.
- **Passagem estreita:** diminuir o boneco para atravessar um espaço.
- **Alcance:** aumentar o boneco para alcançar um ponto distante.
- **Passagem elevada:** encontrar um jeito de superar um buraco sem levantar o personagem além do limite da gravidade.
- **Contrapeso:** usar o peso do personagem para influenciar um objeto ou mecanismo.

## Experimentos de interação

- O cursor pode arrastar objetos do ambiente, não só o bonequinho?
- O bonequinho reage visualmente quando é puxado com muita força?
- O limite de elevação muda conforme o peso?
- Certas ações exigem segurar o clique por mais tempo?

## Para decidir depois

- Estilo de animação (quadros desenhados manualmente, rig 2D etc.).
- Duração do jogo e quantidade de ambientes.
- Tom narrativo: humor, contemplação ou mistura dos dois.
- Música, efeitos sonoros e feedback tátil/visual.
