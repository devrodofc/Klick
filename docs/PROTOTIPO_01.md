# Klick — Protótipo 01

## Objetivo

Validar a movimentação do personagem exclusivamente pelo mouse.

## Mecânicas implementadas

- Clique para agarrar o personagem.
- Arraste para movimentá-lo.
- Solte para aplicar gravidade.
- Ao ultrapassar o limite de altura, o personagem cai.
- Colisão com o chão.

## Parâmetros experimentais

| Parâmetro | Valor inicial |
|---|---|
| Gravidade | 1600 |
| Força de acompanhamento | 18 |
| Velocidade máxima de arraste | 1300 |
| Altura máxima por arraste | 180 px |
| Atrito horizontal | 900 |
