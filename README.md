# Klick

**Klick** é um jogo indie de puzzles, com um bonequinho de palitos desenhado à mão que o jogador controla usando apenas o mouse.

A proposta é uma jornada **linear e contínua**, sem fases tradicionais e sem tutoriais baseados em texto. O jogador aprende experimentando: clica, arrasta, observa e descobre como seguir em frente.

> **Ideia central:** o jogador não dá ordens ao personagem; ele o manipula fisicamente para ajudá-lo a avançar.

## Estado do projeto

📝 **Pré-produção / concepção**. As ideias documentadas podem mudar após os primeiros protótipos.

## Fundamentos

- **Controle principal:** clicar e arrastar o personagem com o mouse, sem WASD.
- **Física:** o boneco sofre ação da gravidade; levantá-lo demais provoca uma queda automática. O comportamento exato ainda precisa ser testado.
- **Puzzles:** exploração de propriedades físicas, como **peso** e **tamanho/altura do corpo**.
- **Descoberta:** instruções mínimas, com pistas visuais, sonoras e reações do personagem.
- **Forma:** experiência curta, feita para ser desenvolvida por uma pessoa.
